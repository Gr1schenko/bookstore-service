# Bookstore service
REST API для интернет-магазина книг. Реализованы эндпоинты для получения списков книг, клиентов и заказов
## Технологии
* Spring Boot 3.5.13
* Java 21
* Maven
* Spring Data JPA
* PostgreSQL
* Flyway
* Lombok
* Docker
## База данных
Приложение подключается к PostgreSQL, запущенному в Docker-контейнере
